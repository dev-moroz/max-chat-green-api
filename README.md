# MAX Chat — Green-API

Веб-клиент для отправки и получения текстовых сообщений в мессенджере MAX через [GREEN-API](https://green-api.com/max).
Тестовое задание на позицию «Фронтенд-разработчик React».

> Проект в разработке. Полный README с инструкцией по запуску, настройке инстанса и архитектурными решениями — в финальном этапе.

## Стек

React 19, TypeScript (strict), Vite, Zustand, Vitest, oxlint, Prettier.

## Скрипты

```bash
npm install
npm run dev        # dev-сервер
npm test           # тесты
npm run typecheck  # проверка типов
npm run lint       # линтер
npm run build      # продакшен-сборка
```
