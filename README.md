# MAX Chat — Green-API

Браузерный клиент для переписки в MAX через [GREEN-API](https://green-api.com/max). Можно войти по данным инстанса, открыть существующие чаты, создать диалог по номеру телефона, отправлять текст и получать новые сообщения через HTTP API.

## Запуск

Нужны Node.js 22+ и авторизованный инстанс MAX в Green-API.

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно `http://localhost:5173`), и введите `apiUrl`, `idInstance` и `apiTokenInstance` из личного кабинета Green-API. Данные сохраняются только в `sessionStorage`: после закрытия вкладки браузер их удалит.

## Настройка инстанса

Для приёма сообщений приложением через `receiveNotification` у инстанса обязательно должны быть включены уведомления. В консоли Green-API откройте нужный инстанс → «Изменить» и задайте:

| Параметр                                          | Значение        |
| ------------------------------------------------- | --------------- |
| Webhook URL                                       | оставить пустым |
| Входящие сообщения (`incomingWebhook`)            | `yes`           |
| Исходящие статусы (`outgoingWebhook`)             | `yes`           |
| Сообщения с телефона (`outgoingMessageWebhook`)   | `yes`           |
| Сообщения через API (`outgoingAPIMessageWebhook`) | `yes`           |
| Состояние инстанса (`stateWebhook`)               | `yes`           |

После входа приложение проверяет эти настройки и покажет предупреждение, если приём входящих выключен. Кнопка в предупреждении сначала просит подтверждение, затем включает нужные типы уведомлений через `setSettings`. Green-API перезапускает инстанс при таком изменении; применение может занять до пяти минут.

Старые сообщения, поступившие в период с выключенными уведомлениями, сервис может не отдать в истории. После настройки попросите собеседника отправить новое сообщение.

## Как пользоваться

1. Войдите с данными инстанса.
2. Выберите чат в списке либо введите номер +7 или +375, чтобы проверить аккаунт и создать диалог.
3. Напишите сообщение. Свои сообщения расположены справа, входящие — слева.

Идентификатор диалога в MAX — это не номер телефона. Номер используется только для `checkAccount`, который возвращает числовой `chatId`; затем все запросы отправляются с `chatId`.

## Архитектура

```
api → store → services → features → app
```

- `api` — типизированный клиент GREEN-API, нормализация сетевых ошибок и безопасный разбор данных из сети.
- `store` — Zustand: сессия отдельно от списка чатов и истории. Чаты и сообщения сохраняются в `localStorage`, учётные данные — в `sessionStorage`.
- `services/notificationPoller` — long-poll `receiveNotification`; каждое уведомление удаляется `deleteNotification`, чтобы очередь не остановилась. Web Locks гарантируют один поллер на инстанс даже в нескольких вкладках.
- `services/historyLoader` — последовательная очередь истории: `getChatHistory` ограничен одним запросом в секунду. При открытии чат загружается целиком в доступном API окне — до 5 000 сообщений за последние 3 месяца.
- `features` — интерфейс входа, создания чата, истории и отправки сообщений.

История и новые уведомления объединяются по `idMessage`, а сообщения сортируются по серверному timestamp. Это не даёт дубликатам от истории и поллера появляться в ленте.

## Ограничения

- API MAX отдаёт максимум 5 000 сообщений за последние 3 месяца. Сообщения, которые поступили, пока соответствующие уведомления были выключены, не попадают в журнал GREEN-API и восстановить их приложением нельзя.
- Приложение работает только с текстом; медиа показываются подписью-заглушкой.
- `checkAccount` применим к номерам РФ (+7) и Беларуси (+375) и может быть ограничен по частоте API.
- API-токен находится в браузере пользователя, поэтому этот вариант предназначен для личного инстанса, а не для публичного многопользовательского сервиса.
